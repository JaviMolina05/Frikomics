# 📖 Guía del Usuario

## 🧾 Introducción
Este sistema permite a los usuarios navegar productos, registrarse, iniciar sesión y administrar su cuenta personal.

---

## ✅ Requisitos
- Navegador moderno (Chrome, Firefox, Edge).
- Conexión a internet.

---

## 🔐 Registro e Inicio de Sesión

### Registro
1. En el header selecciona `Cuenta`. 
2. En la pantalla del Login selecciona `registrarse`.
3. Ingresa tus datos personales.
4. Presiona el botón **Registrar**.

### Iniciar sesión
1. Accede a `Cuenta`.
2. Ingresa tu correo y contraseña.
3. Pulsa **Iniciar sesión**.

---

## 🧑 Perfil de usuario
- Accede desde el menú **Cuenta > Perfil**.
- Edita tus datos personales.
- Guarda los cambios.

---

## 🛍 Productos
- Visualiza productos en `Productos`.
- Puedes navegar, filtrar y ver detalles.

---

## ❓ Preguntas frecuentes

**¿Olvidé mi contraseña?**
Actualmente no hay opción para recuperar contraseña. Contacta al administrador.

**¿Puedo cambiar mi correo?**
Actualmente no hay opción para cambiar el correo. Contacta al administrador.
